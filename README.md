# FitMe

Offline PWA fitness tracker. Data stays on each phone (localStorage). Use Profile > Export for backups.

## Free hosting (GitHub Pages)
1. Create a free GitHub repo (e.g. `fitme`), upload all files in this folder (keep `icons/`).
2. Repo Settings > Pages > Deploy from branch `main` / root.
3. Open `https://<username>.github.io/fitme/` on each phone.
(Netlify Drop at app.netlify.com/drop also works: drag the folder in.)

## Install
- iPhone: open link in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu > Install app / Add to Home screen.

## Two people
Each phone keeps its own data. Profiles tab lets you add more profiles on one phone.
